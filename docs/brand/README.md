# Xecute Brand

The canonical reference is `xecute-brand-board.png`.

## Core Identity

- Mark: angular execution `X` with a forward slash
- Primary orange: `#FE6501`
- Dark field: `#18191D`
- Light field: `#fafafa`

Use the orange mark on a dark field for the primary app icon. In the light product
interface, keep orange as an action and identity accent rather than a large surface
color. Do not substitute the mark with a plain letter `X`.
